# Sales Forecasting MLOps Pipeline

## 1. Project Overview

This project implements an automated machine learning pipeline
for predicting product-store sales revenue using product and
store characteristics.

The pipeline covers data validation, data preparation, model
training, hyperparameter tuning, evaluation, experiment tracking,
GitHub Actions automation, and Streamlit deployment.

**Important limitation:** The supplied dataset does not contain a
sales date column. The current model predicts product-store revenue;
it does not provide genuine weekly, monthly, quarterly, or annual
time-series forecasts.

## 2. Project Objectives

- Validate the source sales dataset.
- Clean the data and create training and testing datasets.
- Train and tune regression models.
- Track model parameters and evaluation metrics.
- Automate pipeline execution using GitHub Actions.
- Save the trained model for reuse.
- Deploy a sales prediction interface using Streamlit.

## 5. Dataset

The dataset describes products and stores and includes attributes
such as product weight, sugar content, allocated display area,
product category, retail price, store size, city tier, and store type.

**Target variable:** `Product_Store_Sales_Total`

Product and store identifiers are excluded from the baseline
features. The target is product-store revenue.

## 6. Pipeline Workflow

1. **Data validation:** Check required columns and summarize data.
2. **Data preparation:** Clean records, prepare features, and split
   the data into training and testing sets.
3. **Model training:** Train and tune a regression model.
4. **Experiment tracking:** Record parameters, metrics, and run details.
5. **Model evaluation:** Calculate MAE, RMSE, and R-squared on the
   held-out test set.
6. **Artifact handling:** Pass files between GitHub Actions jobs.
7. **Model commitment:** Commit the resulting model after successful
   training and evaluation.
8. **Deployment:** Use the saved model in a Streamlit application.
